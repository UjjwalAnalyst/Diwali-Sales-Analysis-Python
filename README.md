# Diwali-Sales-Analysis-Python
Diwali sales analysis using Python and Jupyter Notebook to explore customer behavior, purchase trends, and revenue insights through EDA.
This project performs an in-depth Exploratory Data Analysis (EDA) on Diwali sales data using Python and Jupyter Notebook. The goal is to understand customer buying behavior, identify top-performing products, analyze demographic trends, and uncover business insights that can help improve sales strategies during festive seasons. Using powerful Python libraries like Pandas, NumPy, Matplotlib, and Seaborn, this project cleans, transforms, and visualizes sales data to reveal meaningful patterns.
